
# Portfolio Risk Analytics Dashboard

## Objective

Build a Python-based portfolio risk analytics dashboard that retrieves historical market data, calculates key risk metrics, and visualizes portfolio performance.

## Skills

- Python
- pandas
- NumPy
- Matplotlib
- yfinance
- Portfolio Analytics
- Risk Analytics

## Metrics

- Daily Returns
- Cumulative Returns
- Annualized Volatility
- Rolling Volatility
- Correlation Matrix
- Portfolio Return
- Sharpe Ratio
- Sortino Ratio
- Maximum Drawdown
- Historical VaR
- Expected Shortfall
